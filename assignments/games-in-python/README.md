
# 📘 Assignment: Jogo da Forca

## 🎯 Objective

Pratique manipulação de strings, loops, condicionais, seleção aleatória e entrada de dados em Python ao construir um jogo de adivinhar palavras.

## 📝 Tasks

### 🛠️ Selecionar a palavra e exibir o progresso

#### Descrição
Implemente a seleção da palavra oculta e a exibição do progresso enquanto o jogador adivinha uma letra por vez.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Aceitar palpites de letras e mostrar o progresso da palavra no formato `_ _ _`.

### 🛠️ Controlar as tentativas e encerrar a partida

#### Descrição
Controle as tentativas incorretas e determine o resultado da partida quando o jogador acertar a palavra ou esgotar as tentativas.

#### Requisitos
O programa concluído deve:

- Informar quantas tentativas incorretas ainda restam.
- Encerrar quando o jogador adivinhar a palavra ou esgotar as tentativas.
- Exibir uma mensagem indicando vitória ou derrota.
